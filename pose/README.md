# pose

Yoga and movement studios. Chalk-white canvas, mist-teal panels, deep teal ink,
studio-teal buttons and one chartreuse spark; Funnel Display over Funnel Sans.
Signature: the sequence — Sun Salutation A drawn as numbered pictogram plates,
a highlight moving through them at breath pace with an Inhale / Exhale cue and a
breathing ring. Every class carries its own pictogram (`components/pose.blade.php`,
thirteen figures on a 48-unit grid; add new poses in the same grammar).

Looks: Plate (default — headline beside a wide photo labelled like a pose plate)
and Notation (type-led hero, every class as a tappable plate, no photo).

Photography is CC0 (StockSnap / rawpixel via Openverse) at ~1000px — replace
with generated or studio photography before shipping widely.
